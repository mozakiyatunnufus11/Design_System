# Latihan Container (Design System – CSS in JS)

Membuat komponen **Container** (kotak berisi teks dengan latar warna dan padding) dengan dua cara:

1. Functional Component – `src/ContainerFunctional.jsx`
2. Class Component – `src/ContainerClass.jsx`

## Cara menjalankan

```bash
npm install
npm run dev
```

Lalu buka alamat yang muncul di terminal (biasanya http://localhost:5173).

## Struktur folder

```
latihan-container/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── ContainerFunctional.jsx
    └── ContainerClass.jsx
```
